# 🏥 Hospital Management System (Python)

A console-based **Hospital Management System** built using Python. This application allows managing patient records, doctor allocations, appointment scheduling, pharmacy details, billing, and generating complete patient summaries.

---

## 🚀 Key Features

- **👨‍🮤 Patient Management**: Add and view patient profiles including name, age, gender, and disease/condition.
- **👨‍⚕️ Doctor Management**: Register doctors with their specializations and consultation fees.
- **📅 Appointment System**: Schedule and track patient appointments with specific doctors.
- **💊 Pharmacy / Medicine Management**: Assign prescribed medicines and record pricing for patients.
- **🧾 Billing System**: Automatically calculate total charges combining doctor fees, medicine costs, and lab test expenses.
- **📋 Final Patient Slip**: Generate a complete itemized receipt and medical summary for any registered patient.

---

## 🛠️ Tech Stack & Concepts Used

- **Language**: Python 3
- **Data Structures**: Lists, Dictionaries, Conditional Statements (`if-elif-else`), Loops (`while`, `for`), Functions.
